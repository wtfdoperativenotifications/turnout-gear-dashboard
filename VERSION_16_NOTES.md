# Version 15 — Testing Release

This release is intended as the stable pause point for in-depth operational testing.

## Changes
- Department-owned header language; OperativeIQ is treated as the data source, not the application brand.
- Operational briefing rewritten with clearer action language.
- Workload now shows the approximate number of annual inspections.
- Summary cards renamed to Fully Equipped, Gear Deficiencies, Due This Month, and Warehouse Stock.
- Inspection queue renamed Annual Inspection Work Queue.
- Search expanded to asset tag, serial number, size, member, manufacturer, and location.
- Asset tag, barcode, and serial number are shown as distinct fields.
- Manufacturer and model are shown separately in asset details.
- Gear type/size badges improve table scanning.
- Version label updated to 15.

No Cloudflare variables or secrets need to change.
